# Mac 可行性：真实人体骨架 → GMR → 本仓 G1 → NPZ → MotionLoader

## 范围与修改

用户要求助手自行选择方案，明确本地仅验证可行性。本轮选择无需人体表面模型权重的真实 LAFAN1 BVH，验证公共命名姿态边界之后的链路。正式 AMASS 训练源不变；AMASS 参数→人体骨架仍未验证，不训练。

仍在 `feat/anybody-muse-s2@696d8d44`，origin 为 `https://github.com/Andisyc/Admittance`。只更新本总览及交接；前两轮文档修改一并保留，均未提交/推送。没有修改生产代码、任务 XML、项目依赖或锁。

临时实现和产物留在 `.tmp/mac-gmr-probe/`：`fetch_lafan_clip.py`、`convert_lafan_probe.py`、`render_lafan_probe.py`，源 `lafan1/walk1_subject1.bvh`，产物 `lafan1_walk_g1_probe.npz`、`lafan1_g1_preview.mp4/png`，运行日志及来源 JSON。全部受现有 gitignore 保护，不作为正式转换器交付。

## 输入及依赖

- 沿用前一交接的独立 Mac arm64/CPU 环境和本仓 G1 模型/官方网格。
- 官方来源 `ubisoft/ubisoft-laforge-animation-dataset@94084601bacdf9cc3764b5c73daaeccae6035fac`，`lafan1/lafan1.zip` 内 `walk1_subject1.bvh`；文件 5,471,540 bytes，SHA256 `4c9d591f323ffa660d9de6ef20c5d7077e66b2102a009feedf01afa22a6fbc73`，ZIP CRC32 `e0f9d028` 验证通过。通过 HTTP byte ranges 仅取此成员，约传输 2,255,941 bytes，**未下载 144,051,503-byte 整套 ZIP**。原官方 `license.txt` 同置本地，未上传源文件或转换产物。
- 原文件 7840 帧、30 Hz；GMR 原 loader 执行厘米→米和 Y-up→Z-up，身高使用其明确的默认假设 1.75 m。取原始索引 150–269 共 120 帧，另用 120–149 的 30 帧预热但不导出。保留原始 30 Hz、位置和朝向；没有补帧、假装为 50 Hz、重置初始 XY 或额外贴地修正。
- GMR 来源仍固定 `bb1bbe40774794fceb2a7c579a3464a28e68c844`，使用 `bvh_lafan1`→`unitree_g1` 的官方配置。修复前一轮已定位的 API 参数错位：只在忽略目录的临时 GMR 副本，将 4 处 `solve_ik(..., self.ik_limits)` 改为 `safety_break=True, limits=self.ik_limits`。Mink 1.3.0 的第六位置参是 safety_break，必须显式传限位列表；未修改安装包或项目生产代码。

## 验收结果

真实运行 `convert_lafan_probe.py` 退出 0：

- 每帧实际执行 GMR `retarget` / DAQP，先按关节名取根位姿和 29 个 joint，再用**本仓** `scene_flat.xml` / `mj_forward` 重新计算 31 个刚体（包含 world0），不复用 GMR 的额外刚体索引。全轨迹通过两套模型的关节限位、有限值、根和刚体四元数归一化及非静止检查；最大单关节活动跨度约 1.1965 rad。
- 输出约 3.9667 秒，根首尾位移约 3.1457 m，最大关节速度约 6.3327 rad/s。它们只是该片段的观测值，不是性能或动态可行性标准。
- 根角速度通过当前姿态切空间的 `mj_differentiatePos` 得到局部 free-joint qvel；各 body 的世界系原点线速度/角速度用 `mj_jacBody` 计算。独立 `mj_integratePos` 微扰 oracle 在 5 帧验证：最大线速度误差 5.02e-7，角速度误差 7.67e-7。未复用存在坐标约定疑点的外部 FK helper。
- NPZ 中 joint_pos/joint_vel 为 [120,29]，body_pos/quat/lin_vel/ang_vel 为 [120,31,*]，world0 原点为零；额外保存名字、原始帧索引和明确的 `LAFAN1; NOT AMASS` 来源。
- 真实 `MotionLoader` 正常包入口读取全量数据成功；按当前任务 YAML 的 14 个 tracked body 名转换为当前模型 body id，再读取和逐值比较成功。此为实际新导出产物的 loader 验收，不使用前轮既有机器人 NPZ 代替。
- 使用本仓模型逐帧 `mj_forward` 渲染 640×480、30 fps 预览，视频 521,561 bytes；中帧图像已目视检查机器人完整可见。没有调用 `mj_step`、策略、优化器或训练入口。脚本未执行环境 `MotionCommand` 或动力学 rollout，不能声称接触/平衡或可训练性已验收。
- 附加检查：当前模型 8 个足底接触球表面的世界 Z 在约 [0.00569,0.23093] m；未校正贴地，不据此声称接触一致或步态物理可执行。
