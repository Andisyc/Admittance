## 决定性证据

固定候选后端为 [YanjieZe/GMR@bb1bbe40774794fceb2a7c579a3464a28e68c844](https://github.com/YanjieZe/GMR/tree/bb1bbe40774794fceb2a7c579a3464a28e68c844)。仅将公开源码/XML/JSON 放到 `/private/tmp/admittance-gmr-audit-bb1bbe4` 检查；临时文件不是交付物。未下载原始动作、人体权重或机器人网格，未安装 GMR、创建仿真实例或调用 IK 求解。

- **人体输入不能直连。**本仓 `src/unilab/data/amass.py:load_amass_clip` 读取 packed `poses/trans/betas/gender` 和两种 fps 键；无明确声明时 model_type 为 unknown。GMR `general_motion_retargeting/utils/smpl.py:load_smplx_file` 要求 `pose_body/root_orient` 等字段，显式创建 SMPL-X；其 README 要求 SMPL-X 版 AMASS。历史 E11 的 156 维 poses / 8 维 DMPL 不能单独证明模型身份，更不能靠改键名、截断或补零宣称兼容。当前项目没有用于重建的配套权重；必须核实远端源模型、beta/DMPL 语义与权重。
- **机器人共同关节的声明匹配。**纯 XML/YAML 比较：本仓 `src/unilab/assets/robots/g1/g1.xml`、GMR `assets/unitree_g1/g1_mocap_29dof.xml` 和 `src/unilab/conf/appo/task/g1_motion_tracking/mujoco.yaml` 均为同序 29 个命名 hinge 关节；轴、父刚体与有效关节位置一致。共同命名刚体的父级、pos/quat 声明一致。缺省关节 pos 按零处理，不能将省略属性误报为机械差异；这些仍是静态声明检查，不等于数值 FK 或动力学验证。
- **机器人模型不能整份替换。**GMR 多 8 个固定刚体：head_link、head_mocap、imu_in_torso、left_rubber_hand、left_toe_link、pelvis_contour_link、right_rubber_hand、right_toe_link；其匹配表直接使用本仓缺少的左右 toe_link。另有 15 个关节的 GMR 限位更窄，均落在本仓范围内。不能直接搬用其刚体数组/索引、替换任务 XML 或静默放宽限位。
- **导出格式不同。**GMR dataset 脚本将根四元数从 MuJoCo wxyz 转为 xyzw，导出 PKL 的 root_pos/root_rot/dof_pos/local_body_pos/link_body_list/fps，并默认调整地面高度与初始 XY。本仓 `src/unilab/tasks/motion_tracking/common/motion_loader.py` 消费 NPZ 的 joint_pos/joint_vel、世界系 body_pos_w/body_quat_w/body_lin_vel_w/body_ang_vel_w 与 fps；`MotionCommand` 按当前机器人 body id 索引，包含 world0 的布局必须一致。根坐标预处理、四元数及名字顺序均需显式定义。
- **50 Hz 不能直接依赖 GMR helper 参数。**其快速时间对齐使用 `int(src_fps/tgt_fps)`。纯公式检查：60 Hz/120 帧或 120 Hz/240 帧请求 50 Hz，均实际报告 60 Hz。原 dataset 脚本默认 30 Hz，此处不是其默认行为失败；若本项目采用 50 Hz，必须按时间网格重采样并验证时长/速度。

以上核查使用 `gh api` 获取固定版本小型源码，`uv run` 执行 XML/YAML/NumPy 静态比较及时间公式检查，`rg` 核对输入/导出符号；没有真实数据重建或求解器运行。文档完成后以 `git diff --check` 和交接链接存在性检查验收，不启动训练或整套 CI。

## 条件成立时的接入方向

候选为：**源数据匹配的人体模型重建 → 命名人体全局姿态桥 → GMR 离线重定向 → 根位姿与命名 29 关节轨迹 → 本仓 G1 FK/速度计算 → tracking NPZ**。GMR 需要的 15 个人体帧名与官方 SMPL-H / SMPL-X 关节命名有重合，为桥接提供可能性；名字相同不证明静止姿态、frame offset、形体、尺度或地面约定一致。尚未冻结生产接口，也未承诺 SMPL-H 参数能直接当 SMPL-X 使用。

GMR 为 Mink/QP IK 离线参考生成器，不是 Encoder–Decoder 训练器或真机在线控制器，不提供接触/动力学可执行保证。后续仍须用学习策略在物理仿真中训练，不能以重定向轨迹替代这一闭环。

现有 FK 导出 helper 也需数值验算：外部 `unisim.backend.mujoco.motion_export.compute_tracking_fk` 将声明为世界系的 base_ang_vels 直接写入 free-joint qvel[3:6]；MuJoCo 该角速度段采用局部系。此为源码层面的坐标约定疑点，未执行旋转 oracle，不在本轮修改外部代码或宣称已证明运行误差。
