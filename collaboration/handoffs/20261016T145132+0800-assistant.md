- AMP 与蒸馏从 `Andisyc/ReGait@06c12ee605795daa14817c9db7644ba75a453075` 恢复并适配当前 EnvFactory/调用契约；已完成源码集成，不是空导入垫片。AMP 的 timeout bootstrap 在任务/style reward 混合后加入；蒸馏保留同状态教师标签、学生采集与跨轮数据聚合。
- APPORuntime 接受并验证当前组装入口需要的 runner_kwargs。更新 AGENTS、中英文架构文档与 ADR，明确仓内训练所有权。
- 已发布 unisim 没有历史 sensor 绑定能力。本轮不通过 Python 微步重构改变物理时序；仅修正可选 capability 的类型与明确失败边界，不能因此声称 AMP 仿真已验证。
- 独立集成审查发现并修复迁入源码的满环覆盖风险：SPSC ring 改为可取消背压，learner 复制完成前不释放槽，APPO/HORA collector 同步接入。满环不再丢旧批，调度/吞吐不声明等价。AMP 仅冻结声明的前置 amp 观测，兼容原地复用数组的环境。
