## 改动与闭合边界

- `src/unilab/data/human_motion.py`：显式 SMPL-H（52×3 pose）及匹配 dense NPZ 权重重建共同 22 人体帧。先将所有 beta 与非零 DMPL 线性形变回归至关节，再做全局 FK，与完整 shaped-vertices→joint regression 数学一致；保留原始平移。未知模型、维度缺失、gender 冲突、非零 DMPL 缺权重均拒绝。权重本身没有取得，合成模型测试不能替代真实验收。
- `src/unilab/data/retarget.py`、`tracking_export.py`：明确时间网格 + SLERP，GMR 求解显式 `limits=`，转移根姿态及命名关节，检查完整 29 关节及源/目标轴、reference、物理 frame/共同链条一致。使用本仓模型重新 FK；free-joint 局部角速度通过 body-origin Jacobian 转成世界系速度。输出含 world0 的 NPZ、名字、输入/scene/编译运动学哈希和来源；metadata 预检、同目录临时文件与无覆写原子发布，避免失败残留。
- `scripts/motion/amass_to_g1.py`：薄离线入口，要求显式模型、Z-up 源坐标声明、匹配权重及身高校准，默认目标 50 Hz；不自动猜模型、不自动登录下载权重。只支持当前明确的 packed SMPL-H，不宣称已实现所有 SMPL/SMPL-X AMASS 格式。GMR 仍是可选离线工具，不进入正常数据 reader/训练导入路径，不恢复外部训练运行时。
- `src/unilab/rl/algos/anybody/{__init__,models}.py`：兼容 RSL `MLPModel` 的 `MUSEActorModel`，`.mlp` 为原纯 E/D、normalizer 为 Identity；只允许状态无关 Gaussian，潜码确定性归一化，探索在 raw 29 动作上，E/D 均接收 RL 梯度。采集端、target actor 与 learner 复用现有同一路径和权重同步。TorchScript/ONNX API 明确未验收。
- `common/anybody_observations.py` 与 `conf/appo/task/anybody_g1/mujoco.yaml`：524 维 [goal73, term-major history450, raw mask1]，历史由真实 ObservationManager 维护；参考线速度使用参考 anchor 自身系，当前 base 速度为 root 局部系。目标初始全可见、关闭归一化/编译，Critic 明确为独立 MLP。保留本仓统一 action scale=0.25/default offset，不声称兼容 donor 不同尺度 checkpoint。`motion_file` 必填，拒绝使用默认旧动作冒充训练数据。
- `utils/sim2sim.py`：把 Actor 类、结构与分布配置纳入拒绝不匹配字段；`scripts/train_appo.py` 增加兼容默认 true 的 export 开关，新 profile 显式 false/no_play=true，防止提前触发未验收导出或播放。
- 文档/支持：新增 ADR、更新 datasets README、索引和历史技术记录顶部说明。生成器原本对 APPO 泛化标 Tested，本轮仅对新 anybody_g1 路径保留 Configured，重新生成支持矩阵；继续复用现有 G1 环境注册，没有另外增加未经验收的机器人/后端注册。`.gitignore` 保护新机器人数据及人体模型目录。
